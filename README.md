# 潇湘初梦

## 在线游玩

**[直接打开《潇湘初梦》](https://xiaoxiang-first-dream.nayoagan.chatgpt.site/)**

电脑浏览器打开后，点击“展卷入梦”，从卷架中抽取章节。无需注册或登录。

## 循话游府版 · V11.8

恢复原有开始界面、创作团队和带拿取、封皮翻折、缓慢展开动画的“红楼卷藏”，接入青黛宣纸风三维贾府。

- 第一卷“初入荣府”：点击“走入三维贾府”，自由探索地图、人物、物品和八间内室；交谈时显示对应人物立绘。也可选择“原篇阅读”重温原来的完整视觉小说。
- 第二卷“黛玉葬花”：保留葬花故事、三段内心黛玉对话、人物忆影与三种心境。
- “共读西厢”“秋窗风雨”：可抽卷预览，入梦按钮显示“未完待续”。
- 从贾府点击“回到卷册”，回到同一网站的章节页。“续上前梦”会继续最近游玩的阅读或三维模式，原存档各自保留。

### 随着相逢走遍荣府

贾母留在正房；凤姐在绣房廊前，迎春在茶房，探春在西厢书阁，惜春在叠石高处的听风亭，王夫人在后院曲廊，宝玉在临水亭，雪雁在东侧绣楼。

完成门前引路、拜见外祖母与凤姐之后，三位姊妹可以任意先后拜访。每段对话留下去处线索，手记记下所见；也可在小图标记或循路前往。九段相逢结束后仍能自由探索。旧位置、选择、物件和门扇状态会保留，旧版已完成进度可接上新增游府线。

小地图会自动以金色星芒标出当前去处，光晕以约 2.4 秒的节奏柔和闪动。姊妹分支同时显示所有可拜访地点；手动记下的去处略微突出，完成相逢后自动切换。关闭场景动效或使用系统减少动态效果时，保留静态星芒。标识按屏幕尺寸保持大小，与黛玉的圆点区分。

### 本地运行

安装 Node.js 22.12 或更高版本，双击 `启动潇湘初梦.cmd`，或在仓库根目录执行 `npm start`，打开 http://127.0.0.1:4177/ 。运行已构建游戏无需安装 npm 依赖。

[下载完整入口版游戏](https://github.com/nayoagan-ship-it/xiaoxiang-first-dream/releases/tag/jiafu-v11.8.0) · [三维源代码与操作说明](jiafu-3d/README.md) · [构建说明](BUILDING.md)

浏览器存档依赖相同设备、浏览器和网站地址。公开网站的原阅读存档保留；本地继续使用 4177 端口可接续此前三维进度。

## 作者的话

一枚没玩过Galgame的萌新的初次尝试

之前看蓝色大肥鱼和小克的二创上头了，也想自己手搓一个可爱的二创视频，奈何HeyGen和Runway的免费次数都用完了，Updream花了30人民币结果版权问题不给过审（我真的要哭死）

所以我就近选择了一个好做的领域——主要也是为了完成小组作业，做蓝色大肥鱼Galgame的话老师可能不认识，所以就选择红楼梦里的林黛玉进贾府了。

就像我开头叠的甲，我真没玩过Galgame,最大的接触渠道就是B站上的各种二创，比如著名的0d000721(坏笑)，所以有做的不好的地方还请各位能宽容一些，键盘下留情。

以后这个系列可能会长篇更新，做成一个类似于闯关的形式，争取多做上几回的内容，同时我也希望我的作品能发展出不同于原著中的If线，例如宝黛提前反抗为爱出走、前世姻缘重现今世、宝玉一路科举取士等等，我觉得都很有意思。

嗯……总而言之，这是一款及其轻量的Galgame,大概7-8分钟就结束了，希望能给各位带来一点欢乐就好
