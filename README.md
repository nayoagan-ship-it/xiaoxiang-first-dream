# 潇湘初梦

一枚没玩过Galgame的萌新的初次尝试

之前看蓝色大肥鱼和小克的二创上头了，也想自己手搓一个可爱的二创视频，奈何HeyGen和Runway的免费次数都用完了，Updream花了30人民币结果版权问题不给过审（我真的要哭死）

所以我就近选择了一个好做的领域——主要也是为了完成小组作业，做蓝色大肥鱼Galgame的话老师可能不认识，所以就选择红楼梦里的林黛玉进贾府了。

就像我开头叠的甲，我真没玩过Galgame,最大的接触渠道就是B站上的各种二创，比如著名的0d000721(坏笑)，所以有做的不好的地方还请各位能宽容一些，键盘下留情。

以后这个系列可能会长篇更新，做成一个类似于闯关的形式，争取多做上几回的内容，同时我也希望我的作品能发展出不同于原著中的If线，例如宝黛提前反抗为爱出走、前世姻缘重现今世、宝玉一路科举取士等等，我觉得都很有意思。

嗯……总而言之，这是一款及其轻量的Galgame,大概7-8分钟就结束了，希望能给各位带来一点欢乐就好
