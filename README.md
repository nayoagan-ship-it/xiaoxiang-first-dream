# 潇湘初梦

## 在线游玩

**[点击直接游玩《潇湘初梦》](https://xiaoxiang-first-dream.nayoagan.chatgpt.site/)**

公开访问，无需下载、安装或登录。建议使用电脑浏览器，打开后点击「初入荣府」开始。

点击画面、空格或回车推进剧情；遇到选项时点击选择。存档保存在当前浏览器，清除网站数据会同时清除存档。

下载源码后也可双击 `开始游戏.html` 离线游玩，更多本地运行方式见 [BUILDING.md](BUILDING.md)。

## 三维贾府漫游 · V11.6 青黛宣纸合并版

在 V11.5 完整三维贾府的基础上合入青黛宣纸界面，统一导航、地图、手记、设置与人物对话。继续控制方块黛玉自由探索亭台假山、高低院落和八间内室，交谈时显示对应人物的水彩立绘。

- [查看三维版源码与操作说明](jiafu-3d/README.md)
- [下载合并版游戏与可编辑模型](https://github.com/nayoagan-ship-it/xiaoxiang-first-dream/releases/tag/jiafu-v11.6.0)
- 安装 Node.js 后，在仓库根目录运行 `npm run start:3d`，打开 http://127.0.0.1:4177/ 。

三维版位于独立的 `jiafu-3d/` 目录；原公开网址继续提供二维阅读版。

## 作者的话

一枚没玩过Galgame的萌新的初次尝试

之前看蓝色大肥鱼和小克的二创上头了，也想自己手搓一个可爱的二创视频，奈何HeyGen和Runway的免费次数都用完了，Updream花了30人民币结果版权问题不给过审（我真的要哭死）

所以我就近选择了一个好做的领域——主要也是为了完成小组作业，做蓝色大肥鱼Galgame的话老师可能不认识，所以就选择红楼梦里的林黛玉进贾府了。

就像我开头叠的甲，我真没玩过Galgame,最大的接触渠道就是B站上的各种二创，比如著名的0d000721(坏笑)，所以有做的不好的地方还请各位能宽容一些，键盘下留情。

以后这个系列可能会长篇更新，做成一个类似于闯关的形式，争取多做上几回的内容，同时我也希望我的作品能发展出不同于原著中的If线，例如宝黛提前反抗为爱出走、前世姻缘重现今世、宝玉一路科举取士等等，我觉得都很有意思。

嗯……总而言之，这是一款及其轻量的Galgame,大概7-8分钟就结束了，希望能给各位带来一点欢乐就好
